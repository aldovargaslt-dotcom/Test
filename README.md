# Counter App

A minimalistic counter application built with React, rendered on plain HTML.

## Overview

A clean, SaaS-style counter with increment and decrement controls. Simple, focused, and distraction-free.

## Features

- **Increment (+1)** — Increase the counter value by one
- **Decrement (-1)** — Decrease the counter value by one
- **Live display** — Current count updates instantly on each click

## Tech Stack

- **React** — UI rendering and state management
- **HTML** — Base document structure
- **CSS** — Minimalistic SaaS-inspired styling
